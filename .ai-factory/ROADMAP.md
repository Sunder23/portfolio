# Roadmap проекта

> Статичный сайт-портфолио на React + Vite + TS с self-hosted админкой без бэкенда и БД: контент — JSON в репозитории, сохранение из админки — коммит через GitHub Contents API, хостинг — GitHub Pages.

## Milestones

- [x] **Этап 0 — Каркас** — Vite + React + TS, роутер (HashRouter), workflow деплоя, валидные пустые JSON по схеме. Критерий: пустой сайт открывается на GitHub Pages.
- [x] **Этап 1 — Публичная часть + i18n** — все 4 страницы (Home, Projects, ProjectDetail, About) читают данные из JSON; react-i18next и локаль в hash-роуте с первого дня. Критерий: контент правится в JSON руками → после пуша меняется на сайте; переключение uk/ru/en работает.
- [x] **Этап 2 — Админка: данные** — TokenGate, github.ts (Contents API клиент), CRUD проектов + редакторы profile/skills. Критерий: правка в админке → коммит в репо → сайт обновился.
- [x] **Этап 3 — Админка: картинки** — сжатие изображений в браузере (canvas → webp) и загрузка через Contents API. Критерий: загруженная картинка ≤300 КБ и отображается в проекте.
- [ ] **Этап 4 — Лиды** — контактная форма (shadcn Form + zod) → Google Apps Script relay → Telegram-бот, без утечки токена бота в клиентский код. Критерий: отправка формы приходит сообщением в TG; токен бота отсутствует в бандле.
- [x] **Этап 5 — Полировка** — тёмная/светлая тема, локализованные мета-теги/OG, lighthouse ≥90 по всем категориям, favicon, README.
- [ ] **Этап 6 — Админка в стиле WordPress** — WP-подобная структура (топ-бар + сайдбар с подменю), глобальный контекст языка контента, авто-slug из заголовка, WYSIWYG-редактор (TipTap) для markdown-полей, проекты как отдельные файлы `data/projects/{slug}.json`, таксономии (стек/категория/роль) с чекбоксами вместо ручного ввода. Критерий: создание/редактирование/удаление проекта через новую админку работает без ручного ввода slug и без ручного набора stack-тегов; переключение языка в топ-баре меняет активную вкладку во всех локализуемых полях.
